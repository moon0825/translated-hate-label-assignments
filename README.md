# Relabeling translated hate-speech data with LLMs under target definitions

Materials for *Relabeling translated hate-speech data with LLMs under target definitions reduces false positives on interpersonal insults*.

- [releases/manuscript_20261019/](releases/manuscript_20261019/README.md): the analysis companion. Download [analysis_companion.zip](releases/manuscript_20261019/analysis_companion.zip), extract it and start with its top-level README. Its `reproduce.py` reproduces the reported statistics from the released aggregates and checks file checksums. The archive contains text-free training assignments, aggregate and stratum-level results, the threshold-free results (Supplementary Section S17) and an index from manuscript and supplement tables to data files.
- [releases/manuscript_scirep_20261113/](releases/manuscript_scirep_20261113/README.md): aggregate results for the target-stratified false positives and contrast instructions (Supplementary Section S19) and the normality and non-parametric checks (Supplementary Section S20).

Original corpora and models remain subject to their distributors' access and reuse terms.
