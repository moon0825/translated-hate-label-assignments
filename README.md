# Learning from Translated Hate-Speech Annotations

Materials for *Learning from Translated Hate-Speech Annotations: Label Assignments and Detection Costs*.

The analysis companion is in [releases/manuscript_20261019/](releases/manuscript_20261019/README.md). Download [analysis_companion.zip](releases/manuscript_20261019/analysis_companion.zip), extract it, and start with its top-level README. Its `reproduce.py` reproduces the reported statistics from the released aggregates and checks file checksums.

The archive contains text-free training assignments, aggregate and stratum-level results, the threshold-free results of Appendix A, and an index from manuscript and supplement tables to data files. Original corpora and models remain subject to their distributors' access and reuse terms.
